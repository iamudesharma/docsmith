# Validation evidence — 11 October 2026

The final local build, formatting and Clippy (`--all-targets -D warnings`) pass on Rust 1.88/macOS ARM64. **28 tests** pass. **23 live API checks** pass, including multipart upload, canonical cells, JSON/Markdown/plain text, unit/asset retrieval, auth/tenant cache isolation, both upload/body 413 limits, cancellation, enforced process timeout, crash restart and deletion. See VALIDATION.json and e2e-results.json.

The unit suite covers source graphs and compressed/embedded source, exact synthetic table cells/formulas/merges, logical source order, OCR rotation coordinate mapping, hidden OCR suppression, password/corrupt inputs, XML/entity/archive defenses, PDF geometric table proposals, chart caches, valid OpenAPI references and completed-page checkpoint reuse. Macro code and external resources are never executed/fetched by the direct adapters.

A generated 10,000-row/30,003-cell CSV completes in about 510 ms of extractor time (1.10 s CLI wall time) in a debug build, retaining leading zeros. This is a single small local measurement, not a release-build throughput/soak result. JSON/Markdown/plain text/unit/assets are streamed; lightweight status and asset manifests avoid reparsing large results when polling. See large-input-check.json.

Tesseract's clean/noisy/rotated English and Hindi synthetic fixtures have zero normalized character error in the recorded final run. The sparse-text and rotation policy was added after earlier rotated/Hindi failures. Apple Vision succeeded in individual English/Hindi runs but later repeated runs failed with e5rt errors and a CPU-stage experiment timed out; the helper is implemented, but its local reliability gate has **not** passed. Do not treat runtime language availability as recognition reliability.

SmolVLM2 Q4 plus matching Q8 projector completed native local inference. The constrained ER response was valid JSON but semantically incorrect: expected Users/Orders were labeled as PK/FK nodes, and the expected entity endpoint edge was absent. Canonical graph output remains inferred, with warnings; this model did **not** pass diagram semantic acceptance. The model server's physical footprint snapshot was about 1.1 GB, with substantial preexisting/system swap on the actual 8 GB M1 Air. Sampled RSS does not include all Metal/compressed memory. See benchmark-results.json and vlm-memory-summary.txt. The temporary server was stopped after testing.

The brief's M1 Pro 16 GB, real customer scans/handwriting, complex layout/topology, full legacy formats, Visio/SmartArt graph semantics, Paddle/ONNX complete OCR pipeline, stronger-model comparison, Linux CI/container, long soak and backup-restoration gates remain unrun or deferred. Docker/CI/deployment artifacts are provided; the local Docker socket was unavailable. The service is a tested foundation, not a claim of exhaustive document fidelity or completed production certification.
